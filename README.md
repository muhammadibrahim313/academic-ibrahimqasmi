# Academic Website

Replica-style academic portfolio inspired by Anil Ozturk's layout and customized with Muhammad Ibrahim Qasmi's data.

## Structure

- `index.html` - About
- `education.html`
- `experience.html`
- `competitions.html` - Kaggle competitions
- `coding-competitions.html`
- `hackathons.html`
- `publications.html`
- `community-leadership.html`
- `assets/styles.css`
- `assets/script.js`
- `assets/My_CV.pdf`

## Notes

- Old pages are preserved as redirects:
  - `local-competitions.html` -> `hackathons.html`
  - `patents.html` -> `community-leadership.html`
  - `certifications.html` -> `publications.html`

## Run

Open `index.html` in any browser.
